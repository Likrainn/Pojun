### 不下放（红队版专属）

- **blackgray-hunting skill + detect_domain 域判定 + 黑灰产 Playbook**：打击黑灰产是内部版定位核心（取证固证/资金链路/移交材料），公开版定位通用渗透，混入反而模糊定位。
- **取证模式/隐蔽模式默认值**（forensic_mode/stealth_mode 默认开）：默认值哲学属内部版；`stealth_mode` 本身可作为公开版可选开关另行评估。
- **内置拦截规则默认全关**：公开版默认开（三层闸门）是刻意设计。
- **私有发布链路**（GH_TOKEN 安装/私有 GHCR）：公开版走公开 Release/GHCR。

## Logo 统一注意事项

- 红队版「破军·劈星」：北斗四角星+橙色小星，红橙渐变，透明底；**logo.png 仅 256×256**（公开版是 512×512）——统一时从 `logo.svg`（矢量）重导出 512 PNG，避免 README 大图发糊。
- 同步清单：`web/public/{logo.png, logo.svg, logo-mono.svg, favicon.ico}` + `web/src/app/favicon.ico` + README 头图 + 侧栏（logo-mono）渲染验证；多尺寸 ico 用 ImageMagick 生成。
- 红队版是否同步回公开版旧 logo：**否**（统一即两边都用新 Logo）。

## 实施注意（分叉适配）

- 红队版功能代码在其自身演进线上改过共享文件——移植时以「模块 + 依赖清单」为单位，逐个对齐公开版当前实现（如 auto_finish.go 两侧已不同）。
- KB 种子含黑灰产专属条目：下放时过滤出通用安全知识子集，或以 `audience: internal` 标记隔离。
- Autopilot 与公开版「自动收尾判据」存在语义冲突（relentless vs idle/coverage 收尾）——必须做成模式开关且默认关，文档写清两者互斥关系。
